5.4 Start/Stop Response and Phase Maps under Rectangular-Wave Input ​

Section 5.2 examined an overflow-activated setup with constant input. When the overflow branch does not fill, the conduit develops no backlog, and the machine operates continuously with sufficient material, its start/stop cycle is

T0=L20=6τ,τ=L120.

This cycle does not vary with the constant input rate. If input itself switches periodically between high and low flow, will the setup retain its original period? Will input-induced timing disturbances decay or grow? Can the machine follow the input to form a stable forced response? This section establishes a recurrence from the onset of each overflow to address these questions.

Figure 5.4-1. Top: a functional schematic using the lumped-buffer approximation; it does not represent actual pipe-tile counts. Bottom: response waiting, continuous operation and stopped refilling are distinguished relative to overflow onset. Stage widths are schematic only.

5.4.1 Rectangular-Wave Input and Scope ​

A rectangular wave switches periodically between two values. For Liquid Xiranite input, denote the high and low flow rates, input period, and fraction of the period at high flow by

vH,vL,P,β.

Each input period begins with a high-flow segment of duration

H=βP,0<β<1.

The input is

vin(t)={vH,0≤tmodP<H,vL,H≤tmodP<P.

The average input is

v―=βvH+(1−β)vL.

When the high and low states last equally long, the signal is usually called a square wave. This section allows unequal durations, so we use “rectangular wave.”

Retain Section 5.2's lumped-buffer approximation: ignore transport details within individual buffers and retain transport delay only in the response time from overflow to activation. Choose the branch with enough overflow capacity that it never fills, so inadequate overflow-branch capacity never creates a conduit backlog. Further restrict high flow to below the machine's production fluid-consumption rate. All input during operation then replenishes the production buffer, with no new overflow.

To first study an analytical model with a single uninterrupted operating interval, further assume

6<vL<vH<30.

The low rate exceeds the activation rate limit, keeping this approximation away from intermittent operation caused by sparse activation-fluid arrivals. Systems with low flow below 6 may also synchronize, but activation interruptions must be treated separately; this section's single-interval operating model cannot be applied directly.

We also continue to require uninterrupted material supply and no activation-fluid waste. The trajectories calculated below must satisfy the buffer conditions. Analytical equations use minutes for time and units per minute for flow; numerical tables convert times and intervals into seconds for readability.

5.4.2 Which Output Properties Can Change? ​

The machine produces at a fixed rate while running and produces nothing while stopped. Under the continuous-flow approximation, its gas-production rate is

qgas(t)=30u(t),u(t)∈{0,1}.

The output is therefore a sequence of on/off pulses. Changing the input does not increase the output height during operation, but changes pulse widths, spacing and positions relative to the input. The actual discrete production of one unit every two seconds is outside this approximation.

We accordingly distinguish three questions:

  1. Will timing disturbances be amplified? If one overflow occurs slightly earlier or later than before, will the next deviation grow or shrink? This concerns the gain of a phase disturbance, rather than the ratio of output to input flow amplitudes.

  2. Will output retain the natural period? With constant input, consecutive overflows are six response times apart. Does that interval remain fixed under rectangular-wave input?

  3. Will a stable forced response form? Can the machine start at a fixed position within the input period, or repeat only after several input periods?

Material conservation first provides a long-term constraint. With no waste or input starvation, no reduction of actual input by back-blocking, and bounded inventory and unused activation credit, the long-term operating fraction and mean gas-production rate are

u―=v―36,q―gas=56v―.

This does not determine pulse arrangement. The same average output can correspond to uniform start/stop intervals, alternating short and long intervals, or more complex timing.

5.4.3 A Recurrence from Overflow Onset ​

(1) Choosing the Same Marker Event in Every Cycle ​

Denote successive overflow-onset times by

an.

At that instant the machine buffer has just filled, the machine has not yet started, and input begins entering the overflow branch. We select the same event in each machine cycle; its phase within the external input period may vary.

The machine starts after the response time. The fluid entering the overflow branch before startup, eventually used to activate this operating interval, is

An=∫anan+τvin(t)dt.

Because overflow stops after startup, this batch determines the uninterrupted operating time:

Wn=An6.

Operation ends at

bn=an+τ+Wn.

(2) The Next Cycle Begins When Cumulative Input Reaches Six Times the Activation Amount ​

The production material consumed during this operation is

30Wn=5An.

From startup until the machine buffer next fills, all input supplies production and replenishes the buffer. Cumulative input during that interval therefore equals the production consumption above. Adding the fluid used for activation before startup gives

∫anan+1vin(t)dt=6∫anan+τvin(t)dt.

This is the basis of the recurrence. First calculate input over one response window, then find the time when cumulative input reaches six times that amount to determine the next overflow.

Define the cumulative-input function

Q(t)=∫0tvin(s)ds.

Input is always positive here, so this function is strictly increasing and invertible. The recurrence is

an+1=f(an)=Q−1[6Q(an+τ)−5Q(an)].

The individual overflow interval is

Tn=an+1−an.

For constant input, the cumulative-input function is linear and the recurrence reduces to

an+1=an+6τ.

recovering Section 5.2's natural period.

(3) Every Trajectory Must Satisfy the Buffer Assumptions ​

Input is below 30 while the machine operates, so its buffer decreases continuously and reaches its minimum at the end of operation:

Slow,n=C1−∫an+τbn[30−vin(t)]dt>0.

A conservative sufficient condition independent of the initial phase is

C1>(30−vL)vHτ6.

Also, the total sent into the activation branch in each cycle is at most the high rate times the response time. Under the retained inventory approximation, capacity sufficient to hold this entire batch guarantees that the branch does not fill:

C2>vHτ.

This conservative condition is convenient for choosing numerical examples; the actual required capacity may be smaller.

5.4.4 From Absolute Time to a Phase Map ​

(1) Tracking Only Where Overflow Occurs Within an Input Period ​

Periodic input satisfies

Q(t+P)=Q(t)+Pv―,f(t+P)=f(t)+P.

Define the overflow phase

ϕn=anmodP.

Iteration can then be performed within a single input period:

ϕn+1=g(ϕn)=f(ϕn)modP.

When calculating actual cycle lengths, also retain the number of input periods crossed by the recurrence; the phase modulo the period alone is insufficient.

For a rectangular wave, cumulative input and its inverse are piecewise linear. Thus, after appropriately unwrapping modulo jumps, the phase map is piecewise affine. Different pieces correspond to the response window and the next overflow falling in different high- and low-flow segments.

(2) Input Timing Determines Each Cycle Length ​

Denote the total overlap of the response window with high-flow segments by

hn.

Then

An=vLτ+(vH−vL)hn.

More high-flow overlap means more activation fluid and longer operation. The next overflow time must additionally be determined from subsequent actual cumulative input.

Denote average input over the response window and over the complete current interval respectively by

v―τ,n=Anτ,v―T,n=Q(an+1)−Q(an)Tn,

The recurrence then gives

Tn=6τv―τ,nv―T,n.

The interval equals the natural period only when these two averages coincide. Equal long-term average input does not guarantee the same period in every cycle.

(3) What Responses Do Fixed Points and Periodic Orbits Represent? ​

If the phase map has a fixed point, actual overflow times satisfy

f(a∗)=a∗+mP.

Overflow then begins at the same input phase every integer number of input periods. One operation per input period corresponds to taking that integer as one.

If phase repeats only after multiple iterations,

ϕn+k=ϕn,∑j=0k−1Tn+j=mP.

Individual intervals may then differ, but the entire timing pattern repeats. Absence of a one-to-one fixed point does not imply absence of other fixed points or periodic orbits.

5.4.5 Existence and Stability of One-to-One Synchronization ​

(1) First Restricting Response-Window Length ​

For an analytical branch that is easy to interpret, first take

τ<min(βP,(1−β)P).

A response window then crosses at most one input transition. The full recurrence does not require this restriction, but the synchronization intervals and piecewise interpretation below do.

One-to-one synchronization requires each interval to equal the input period, so

A∗=Pv―6.

Fluid input over the response window lies between the all-low and all-high extremes. An interior synchronized solution, whose window endpoints avoid transition times, exists when

6vLτv―<P<6vHτv―.

Synchronized solutions may still exist at the boundaries, but must be checked using the one-sided pieces; the interior stability conclusions below do not apply directly.

(2) Falling-Edge Synchronization Phase ​

Consider a window starting at high flow and ending at low flow. Its high-flow duration satisfies

vLτ+(vH−vL)h∗=Pv―6.

Therefore,

h∗=Pv―/6−vLτvH−vL,

The overflow phase is

ϕ∗=βP−Pv―/6−vLτvH−vL.

As the input period lengthens, synchronization requires more activation fluid. Overflow must begin further ahead of the falling edge so that more of the response window covers high flow.

(3) The Amplification Factor of Phase Disturbances ​

Away from input transitions, differentiating the absolute-time recurrence gives

f′(a)=6vin(a+τ)−5vin(a)vin(f(a)).

Under synchronization, the next overflow has the same input phase as the current one. The local slope at a falling-edge synchronized point is therefore

λ=6vLvH−5.

Define a timing deviation relative to the synchronized trajectory:

an=a∗+nP+εn.

Provided that the current and next iterations remain in the same linear piece, the exact relation is

εn+1=λεn.

Thus, local stability of the falling-edge synchronized point requires

|λ|<1⟺23<vLvH<1.

Combining this with the selected flow range gives

6<vH<30,max(6,23vH)<vL<vH.

This guarantees local stability when the synchronized point exists. The existence interval for the input period, the short-window condition, and the buffer conditions must also all hold.

(4) Properties of Other Synchronization Branches ​

If the response window crosses a rising edge, the local slope at synchronization is

λ↑=6vHvL−5>1.

This is local sign-preserving expansion: a slightly later overflow collects more activation fluid and further delays the next overflow. The synchronized point is unstable.

If the response window lies entirely within one flow state and that position happens to form a synchronized solution, the local slope is one and phase error does not contract. Such synchronization occurs at boundary parameters of the existence interval above. Solutions at transitions also require checking both one-sided maps.

5.4.6 Numerical Examples: Convergence, Flips and Neutral Responses ​

All the following examples use

L=8,τ=4 s,P=24 s,β=12.

High flow therefore ends at second 12 of every input period, and the natural period is also 24 seconds. The falling-edge synchronization window covers 2 seconds each of high and low flow, giving the synchronized overflow phase

ϕ∗=10 s.

All calculations below use the full cumulative-input recurrence. To satisfy the buffer assumptions, the model may use a combined machine-and-connecting-pipe capacity of 6 and an overflow-branch capacity of 2. These capacities also meet the conservative conditions for the subsequent numerical examples; they are not measurements of a specific setup's actual capacity.

(2) A Locally Constant Map: Eliminating the Deviation in One Iteration ​

With zero local slope, the phase map is constant on the current piece. As long as the input phase stays in that piece, different small deviations map to the same synchronized phase. This one-step recovery relies on the piecewise-affine structure: a zero derivative alone in a general nonlinear map does not guarantee one-step recovery.

The window-length condition also holds throughout this range, and all falling-edge synchronized points are locally stable. Thus, input can lock a setup whose natural period is 24 seconds to a range of different periods.

(4) Neutral Flipping: Returning to the Original Phase after Two Iterations ​

When the local slope is exactly minus one, the phase map swaps equally distant positions on opposite sides of the synchronized point. If both iterations remain in this piece, the second iterate is the identity:

εn+1=−εn,εn+2=εn.

A family of neutral period-two orbits exists near the synchronized point. Nonzero disturbances neither converge nor grow; the initial deviation determines the alternating amplitude.

Take

vH=18,vL=12,λ=−1.

With an initial deviation of 1 second, overflow phase alternates between seconds 11 and 9. Actual overflow times are

11,33,59,81,107,… s.

The intervals therefore alternate as

22,26,22,26,… s.

More generally, if the deviation alternates between a value and its negative, the two intervals are

P−2ε,P+2ε.

Input repeats every 24 seconds, while the complete output timing for a nonzero disturbance repeats every 48 seconds. This is a neutral response without asymptotic attraction: nearby initial phases may stay close but do not converge to the same period-two orbit.

When the input period lies outside the one-to-one synchronization existence interval, the phase map lacks a fixed point corresponding to one operation per input period. The trajectory cannot maintain that synchronization, but other periodic orbits or fixed-phase responses spanning multiple input periods may still exist.

(3) Checking Multi-Cycle Responses ​

For a periodic phase orbit avoiding piece boundaries, multiply the local slopes of the pieces along the orbit:

Λk=∏j=0k−1g′(ϕj).

A product of magnitude below one indicates a locally attracting orbit; above one, a locally repelling orbit; equality to one requires further examination. For the exact piecewise-affine map used here, if the full composition is locally the identity, a neutral family of periodic orbits results.

This extends fixed-point stability analysis to responses repeating after multiple input periods. If an orbit crosses a piece boundary, use both one-sided maps or directly examine nearby trajectories, rather than applying a single derivative.

5.4.8 Main Results and Scope of Validity ​

Starting from Section 5.2's large-capacity overflow-branch case, this section compresses the full buffer process into a recurrence for overflow times:

an+1=Q−1[6Q(an+τ)−5Q(an)].

It gives individual operating times, overflow intervals and input-phase evolution together. Returning to the opening questions:

QuestionConclusion
Is output-pulse height amplified?Gas output while running remains 30; input mainly changes operating duration and start/stop timing.
Are phase disturbances amplified?This depends on map slope. Falling-edge synchronization may exhibit sign-preserving contraction, flip contraction, neutral flipping or flip expansion.
Does output retain its natural period?Generally no. Input within the response window and subsequent cumulative input jointly determine each interval.
Can a stable forced response form?Yes. An existing, locally stable one-to-one synchronized point can make the machine follow the input period rather than its original natural period.
Is behavior necessarily irregular outside the stable range?No. Critical points and other pieces can produce neutral period-two orbits; other parameters require checking higher-order synchronization or phase slipping.
Does equal average input imply equal average output?With no waste, no reduction in actual input, and bounded inventory and activation credit, long-term mean output is still determined by material conservation.

Separating these factors explains how external input modifies the natural period and distinguishes stable synchronization, critical alternation, and other responses after destabilization.
