Some Research and Searches on 1/n Blocking Flow ​

Source page ID: 7IIqNDoItC2dFP65ZsyOaQ ｜ Open in Tencent Docs

Definitions and Notation ​

All algorithms below work only for odd q. For even q, first factor out the part containing 2.

Graph Structure ​

The complete graph looks like this:

In→C0→⋯→Ck−1→Sk−1→⋯→S0→Out

There are k splitters and k convergers, each with three branches. This path is the main chain; the remaining connections are recirculation edges.

Permutations ​

Introduce two permutations σ and π of (0,⋯,k−1), adding recirculation edges Si→Cσi and Si→Cπi to the main chain. If σi=πi, there is a double edge.

Main-Chain and Recirculation Flows ​

Main-Chain Flows ​

Let Ai be the input flow to converger i and Bi the output flow from splitter i:

In→A0C0→A1⋯→Ak−1Ck−1→Ak=BkSk−1→Bk−1⋯→B1S0→B0Out

Recirculation Flows ​

Write the recirculation flow from splitter i to converger j as Fi→j. We have

Fi→j=min{Bi,Aj}

because:

  1. All A0,⋯,Ak−1 are blocked, all B0,⋯,Bk−1 are flowing, and Ak=Bk is full.
  2. If Si→Cj is blocked, then Fi→j=Aj and Aj≤Bi.
  3. If Si→Cj is flowing, then Fi→j=Bi and Bi≤Aj·

Computing Flows from Permutations ​

For given k and permutations σ and π, we always have

Ai+1=Ai+Fσi−1→i+Fπi−1→iBi+1=Bi+Fi→σi+Fi→πi

Initialize every A and B to 1, then iterate. Since:

  1. Ai(t) and Bi(t) can only increase monotonically with t;
  2. Ai+1=Ai+Fσi−1→i+Fπi−1→i≤3Ai−1⇒Ai≤3iA0=3i, so they are bounded; likewise Bi≤3i;
  3. All Ai and Bi are integers;

the iteration eventually converges to a fixed point. At that point, the flows Ak and Bk give the denominator q.

Algorithm ​

Temporarily set every A and B to 1

do
    update A in order j = 0,1,...,k-1
    update B in order i = 0,1,...,k-1
while the current iteration differs from the previous one

output q = A[k] = B[k]

In this algorithm, temporarily set every A and B to 1; repeatedly update A in order j = 0,1,...,k-1, then B in order i = 0,1,...,k-1, until the current iteration matches the previous one; output q = A[k] = B[k].

Method Two: MILP Feasibility Search ​

Write the recurrence relations directly as constraints and leave the rest to the solver 😋

For target fraction 1/q, the variables and constraints follow.

Main-Chain Flows (Integer) ​
1≤Ai≤q1≤Bi≤q

where i=0,1,⋯,k.

Binary Variables Selecting Recirculation Edges ​

Since MILP cannot directly express a permutation, use “one-to-one selection” with “select exactly one” constraints:

zi→jσ∈{0,1}zi→jπ∈{0,1}

where i,j∈{0,1,⋯,k−1}. zi→jσ=1 means σi=j, and similarly for π.

To ensure exactly one selection, add for each i=0,⋯k−1:

∑j=0k−1zi→jσ=1∑j=0k−1zi→jπ=1

and for each j=0,⋯k−1:

∑i=0k−1zi→jσ=1∑i=0k−1zi→jπ=1

In plain English: make [zi,j] a permutation matrix.

Graph Complexity Conjecture: O(⌈log3⁡q⌉) ​

Since Ak=q≤3k, always k≥⌈log3⁡q⌉. Experimental evidence supports this too, but it provides only a lower bound, not an upper bound.

Some values, q=23 and q=25, require k=⌈log3⁡q⌉+1 to be represented, as proved by exhaustive enumeration.

This suggests ⌈log3⁡q⌉≤k≤⌈log3⁡q⌉+1.

As for algorithmic complexity, I don't know, meow. Perhaps a fast inverse algorithm can be found.
