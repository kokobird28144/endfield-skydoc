Three-State MILP Method — madSUN & jnk ​

Source page ID: zYHEMI5ffFh10ksMQjNW7h | Open in Tencent Docs

This method has greater symmetry than the original MILP, giving faster solving and a somewhat more elegant formulation.

Compared with the first version, two variables—blocked and flowing—represent three states (normal, blocked, full):

Blocked?Flowing?Edge state
NoNoInvalid
YesNoBlocked
NoYesFlowing
YesYesFull

For readability, this description slightly simplifies the actual MILP constraints, for example omitting Big-M linearizations of branches.

Variables ​

For each edge e=(u,v)∈E:

  • ve∈[0,1]: flow rate (v).

  • veH,in∈[0,1]: high-flow-state rate at the inlet (v_H_in).

  • veL,in∈[0,1]: low-flow-state rate at the inlet (v_L_in).

  • veH,out∈[0,1]: high-flow-state rate at the outlet (v_H_out).

  • veL,out∈[0,1]: low-flow-state rate at the outlet (v_L_out).

  • be∈{0,1}: whether blocked (is_blocked).

  • b¯e∈{0,1}: whether flowing (is_unblocked).

Constraints ​

Flow Conservation ​

For every internal node u (u≠In and u≠Out):

∑e∈δ−(u)ve=∑e∈δ+(u)ve

Determining Flow States ​

For each edge e:

ve=veL,in=veH,outif be=1ve=veH,in=veL,outif b¯e=1

and

veH,in≥veL,in,veH,out≥veL,out

Also require

be+b¯e≥1

Intuitively:

  1. At a splitting node, blocked downstream flow is lower than flowing downstream flow.

  2. At a merging node, flowing upstream flow is lower than blocked upstream flow.

  3. An edge cannot be neither blocked nor flowing, but may be both: full.

Full State ​

be=1∧b¯e=1⟹ve=1

That is, the edge has reached its flow capacity.

Equal Splitting (Shared Variables) ​

  • All outgoing edges of splitting node u share vH,in:
veH,in=ve′H,in,∀e,e′∈δ+(u)
  • All incoming edges of merging node u share vH,out:
veH,out=ve′H,out,∀e,e′∈δ−(u)

Intuitively, all flowing downstream branches at a splitting node have equal rates, and all blocked upstream branches at a merging node have equal rates.

Boundary Blocking ​

  • Outgoing edges of the source:
be=1, ∀e∈δ+(In)
  • Incoming edges of the sink:
b¯e=1, ∀e∈δ−(Out)

These match the basic blocking-flow-limiting setup.

Blocking Propagation ​

Splitting node u (unique incoming edge e∗(u), outgoing edge set O(u)=δ+(u)):

b¯e≤b¯e∗(u),∀e∈O(u)b¯e∗(u)≤∑e∈O(u)b¯e+be∗(u)

Merging node u (unique outgoing edge e∗(u), incoming edge set I(u)=δ−(u)):

be≤be∗(u),∀e∈I(u)be∗(u)≤∑e∈I(u)be+b¯e∗(u)

Intuitively:

  1. A splitting node has a flowing outgoing edge if and only if its incoming edge flows.

  2. A splitting node's incoming edge is blocked if and only if all outgoing edges are blocked.

  3. A merging node has a blocked incoming edge if and only if its outgoing edge is blocked.

  4. A merging node's outgoing edge flows if and only if all incoming edges flow.

This seems to handle full edges differently from the old implementation. In fact, when a splitting node's incoming edge or merging node's outgoing edge is full, statements 2 and 4 hold automatically and impose no constraint. As in the old version, all rules therefore stop propagating at full edges.
