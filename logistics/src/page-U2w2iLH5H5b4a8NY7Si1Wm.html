Proof of Depot-Edge Flow Uniqueness ​

This approach proves the proposition by introducing stable-assignment theory.

Stable Assignments ​

Let H=(L⊔R,E) be a finite bipartite graph. Each edge has positive capacity ce and each vertex positive quota Qv. Every vertex partitions its incident edges into nonempty ordered groups

Πv=(πv1,…,πvsv),

where lower group indices mean higher priority, and edges within a group have equal priority. Write jv(e) for the index of the group containing e.

For a local request vector z, with 0≤ze≤ce, define the acceptance operator Cv as follows. If ∑eze≤Qv, accept everything. Otherwise let h be the first group whose cumulative request reaches Qv, and let

r=Qv−∑j<h∑e∈πvjze>0.

Choose a truncation value λ satisfying ∑e∈πvhmin(ze,λ)=r, and set

(Cv(z))e=ze,jv(e)<h;(Cv(z))e=min(ze,λ),jv(e)=h;(Cv(z))e=0,jv(e)>h.

The required value is unique within 0≤λ≤maxe∈πvhze.

Definition: y is a feasible assignment if 0≤ye≤ce and each vertex's total incident flow does not exceed Qv. For ye<ce, if there exists 0<ε≤ce−ye such that

(Cv(yv+ε1e))e>ye,

then vertex v is willing to increase edge e.

An edge is blocking if both endpoints are willing to increase it. A feasible assignment with no blocking edge is stable.

Lemmas ​

Lemma 1.1 Necessary and sufficient conditions for willingness to increase.

Suppose y is feasible and ye<ce.

If ∑fyf<Qv, v is willing to increase every unsaturated edge. If the total equals Qv, let h be the last group containing positive flow and λ=maxf∈πvhyf. Then

v is willing to increase e⟺jv(e)<h or (jv(e)=h and ye<λ).

Proof. If the quota is not filled, choose ε below both the remaining quota and edge capacity; the increase is fully accepted.

Now assume the quota is filled. Since Qv>0, h exists and λ>0.

If jv(e)<h, simply let group h bear the reduction corresponding to the increased flow.

If jv(e)=h and ye<λ, choose positive ε smaller than the remaining edge capacity, λ, and (λ−ye)/2. After increasing the request, group h's new truncation value λ′ lies in [λ−ε,λ]. At λ, the group total increases by ε; lowering the height to λ−ε removes at least ε from at least one formerly maximal edge. Since ye+ε<λ−ε≤λ′, all of e's additional request remains. Thus the vertex is willing to increase it.

If jv(e)=h and ye=λ, any permitted positive increase leaves the vector truncated at λ unchanged. This height still exactly fills the remaining quota, so the accepted amount on edge e remains λ=ye; the vertex is unwilling to increase it.

If jv(e)>h, all groups through h already fill the quota. Increasing a later group's request does not change this; the entire additional request is rejected.

∎

External Theorem 1.2 Results from the literature.

For this stable-assignment model, we use these proved results:

  • Stable assignments exist.
  • Every vertex's total incident flow is the same in all stable assignments.
  • There is an exact polynomial-time stable-assignment algorithm.

Constructing the Stable-Assignment Model and Proving the Result ​

Construct H, splitting each original vertex v into two vertices vin and vout. The left and right sides are

L={vout:v∈I}∪W+,R={vin:v∈I}∪W−.

For each original edge e=(u,v), add edge eH of capacity ce. Its left endpoint is the ordinary node's uout or source depot u; its right endpoint is the ordinary node's vin or destination depot v.

Let Q=⌈maxe∈Ece⌉+1 and set every vertex's quota to Q.

For each v∈I, add distinctly numbered auxiliary edges av,bv between vout and vin, each of capacity Q.

The priority groups are

Πvout=({av},{eH:e∈δ+(v)},{bv}),Πvin=({bv},{eH:e∈δ−(v)},{av}).

Lemma 2.1 Suppose an ordinary node's original input and output totals both equal t, with 0<t<Q. Set

Type A: yav=Q−t,ybv=0;Type B: yav=0,ybv=Q−t.

Neither case has a blocking auxiliary edge.

Proof: Each of av,bv has lowest priority at one endpoint, which therefore rejects it.

Theorem 2.2 Every basic feasible configuration (x,σ) extends to a stable assignment y on H while preserving every original-edge flow:

yeH=xe.

Construction: Let F be the fixed-edge set. Choose each ordinary node's configuration from the table, then assign auxiliary flows using Lemma 2.1.

Original nodeConditionAuxiliary configuration
Splitter vp(v)∈F, or its state is EMPTYType A
Splitter vp(v)∉F and its state is FULLType B
Converger vq(v)∉F and its state is EMPTYType A
Converger vq(v)∈F, or its state is FULLType B

This gives a stable assignment.

Lemma 2.1 shows auxiliary edges do not block. We next prove original edges do not block.

Proof:

An original edge at capacity plainly does not block. Suppose e=(u,v) is below capacity, so e∉F.

If its state is EMPTY, ιe=1 and u is not a source depot.

  • If u is a splitter: a fixed input assigns type A. Otherwise propagation forces the input also to have ι=1; this single-branch edge cannot be PARTIAL, so it is EMPTY, again assigning type A. By the local maximum rule, e is maximal among all original outputs, including saturated ones. The output side therefore rejects eH.
  • If u is a converger: e is its sole output, nonfixed and EMPTY, assigning type A. A sole output is automatically maximal, so the output side rejects eH.

If its state is FULL, ωe=1 and, since e is unsaturated, v is not a destination depot.

  • If v is a converger: a fixed output assigns type B. Otherwise propagation forces the output to have ω=1; this single-branch edge cannot be PARTIAL, so it is FULL, again assigning type B. By the local maximum rule, e is maximal among all original inputs. The input side therefore rejects eH.
  • If v is a splitter: e is its sole input, nonfixed and FULL, assigning type B. A sole input is automatically maximal, so the input side rejects eH.

For state PARTIAL, repeat both the splitter-side and converger-side arguments above; both endpoints reject eH.

Theorem 2.3 (Depot-Edge Flow Uniqueness)

For an idealized logistics system (G,c), define depot-adjacent edge set B by

B={(u,v)|u∈W+ or v∈W−}

Any two valid solutions x,x′ satisfy

∀e∈B,xe=xe′

Proof: External Theorem 1.2 says that for the bipartite graph corresponding to any basic feasible configuration, every vertex's total flow agrees across solutions. A depot node has just one edge in that graph, so its flow is invariant across all basic feasible configurations. ∎
