(Actually inspired by jnk.)

For edge e=(u,v), define states ι(e),ω(e):E→{0,1}.

ι(e)=1 means:

Whenever u attempts to insert an item into e, e has space to accept it.

ω(e)=1 means:

Whenever v requests an item from e, e has an item available to output.

Cipolla_'s Definition ​

Equivalent to 恒星泰斗's definition. Note that overlapping terminology may cause ambiguity.

  • Every edge must be flowing or blocked, possibly both. A full belt is necessarily both flowing and blocked.
  • A splitter's upstream is flowing ⇔ at least one downstream branch is flowing.
  • A splitter's upstream is blocked ⇔ all downstream branches are blocked. This fails when the upstream belt is full.
  • A converger's downstream is blocked ⇔ at least one upstream branch is blocked.
  • A converger's downstream is flowing ⇔ all upstream branches are flowing. This fails when the downstream belt is full.
  • If a splitter has a flowing downstream branch, every maximum-rate branch flows and all other branches do not.
  • If a converger has a blocked upstream branch, every maximum-rate branch is blocked and all other branches are not.
  • All system inputs are blocked; all outputs are flowing.

jnk's Definition ​

Equivalent to 恒星泰斗's definition. Note that overlapping terminology may cause ambiguity.

  • Every belt is in one of three states: nonblocked, both flowing and blocked, or nonflowing.
  • A flowing splitter input implies at least one flowing output; all outputs nonflowing implies a nonflowing input.
  • A nonflowing splitter input implies at least one nonflowing output.
  • A nonblocked splitter input implies at least one nonblocked output.
  • All flowing splitter outputs have equal flow; nonflowing outputs have no greater flow.
  • A nonflowing splitter input with a flowing output has input flow 1.
  • A nonflowing converger output implies at least one nonflowing input.
  • A nonblocked converger output implies every input is nonblocked.
  • All blocked converger inputs have equal flow; nonblocked inputs have no greater flow.
  • A nonflowing converger input with a flowing output has input flow 1.
  • Every system output is nonblocked. When source output edges have equal flow and are nonblocked, they must carry actual flow.
