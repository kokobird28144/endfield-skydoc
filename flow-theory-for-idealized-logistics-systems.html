Flow-Calculation Theory for Idealized Logistics Systems ​

Basic Definition ​

An idealized logistics system replaces the actual game system with decimal-valued flows and a directed graph, producing an idealized flow model.

The general definition is:

Given a finite directed multigraph G=(V,E) and a capacity ce≥0 on every edge e, (G,c) is an idealized logistics system. Write δ−(v) and δ+(v) for the sets of edges entering and leaving v. For splitter v, write p(v) for its unique input; for converger v, write q(v) for its unique output.

Indegree and outdegree determine node type. For convenience, a node with indegree and outdegree both 1 is treated as a splitter.

TypeIndegreeOutdegreeNotation
Source depot01W+
Destination depot10W−
Splitter11, 2, or 3S
Converger2 or 31C

Every edge satisfies 0<xe≤ce. Write I=S∪C for ordinary nodes and W=W+∪W− for depot nodes. Ordinary nodes obey flow conservation:

∑e∈δ−(v)xe=∑e∈δ+(v)xe,v∈I.

Flow Calculation Without Blocking ​

If each splitter divides incoming flow exactly equally:

∀v∈S,∀e∈δ+(v),xe=1|δ+(v)|xp(v)

this restriction and conservation yield a linear system. Gaussian elimination gives every edge flow.

Definition of Idealized Systems with Blocking ​

In practice, splitters cannot divide flows equally when certain edges reach their transport-rate limit or their buffer-item limit. These cases are collectively blocking. Several detailed definitions have appeared, mostly equivalent.

This article adopts only the first two definitions.

Depot-Edge Flow Uniqueness Theorem ​

For an idealized system (G,c), define the depot-adjacent edge set B:

B={(u,v)|u∈W+ or v∈W−}

Any two valid solutions x,x′ satisfy:

∀e∈B,xe=xe′

Computing Depot-Edge Flows ​

There is no polynomial method that computes all valid flow solutions, because there may be exponentially many: consider copying a multiple-solution graph n times and connecting the copies end to end.

However, the stable-assignment proof above transforms the idealized system into a stable-assignment model, allowing existing algorithms to compute depot-edge flows in polynomial time.
