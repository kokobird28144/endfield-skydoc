4.1 Modeling Blocking-Based Production Dynamics: Discrete, Continuous and Machine Dynamical Models ​

Source page ID: p8Q45DjLw7ZZB74NhCzwor | Open in Tencent Docs

This is a brief treatment; see the paper for detailed mathematical models.

Discrete Model ​

The discrete model reflects actual in-game production structures as completely as possible, considering:

  1. Items move individually from upstream to downstream, stopping when blocked. Machines check frame by frame whether internal capacity meets production conditions. If so, they consume the appropriate inputs, produce, and output finished products downstream after some time.

  2. Belt transport delays are included; fractional items do not exist.

Continuous-Flow Model ​

The discrete model is poorly suited to theoretical analysis of whole-line dynamics, so we further simplify it to a continuous-flow model.

In brief, this model focuses on two dynamic variables: flow rate and inventory. Flow determines inventory changes, and inventory acts back on flow. Machine-buffer inventory also determines whether a machine produces.

The simplifications are:

  1. Stop treating items individually; focus on average flow rate, the number passing in a time interval.

  2. All values may be noninteger; fractional items may be produced or consumed, provided recipe ratios match.

  3. Ignore belt transport delays, treating the flow response to inventory as instantaneous.

Although this omits real features such as output phase and delay, it effectively captures the main interaction in production controlled by blocking: inventory and flow acting on each other. For clock-signal modeling, by contrast, these features should not be ignored.

Now consider the dynamical equations. The inventory equation comes from material conservation: the next inventory is the smaller of capacity C and current inventory s(t) plus incoming flow over the interval, minus total downstream output.

The capacity term additionally includes KUdt, representing the machine's production-buffer slot. Adding virtual storage equal to the input amount processed over this interval permits constant s(t) anywhere between 0 and C during full-rate operation.

sj(t+dt)=min(Cj+KjUdt,sj(t)+vj(t)dt)−Kj∑e∈outve(t)dt

The flow equation says that flow is the smaller of upstream output and downstream acceptance. This expresses blocking's effect on flow. With unlimited downstream acceptance, there is no blocking and v always equals upstream output. All variable behavior can then be determined in one upstream-to-downstream traversal.

ve(t)=min(qupstream(t),cdownstream(t))

Machines transform items, so their rate equations must also be added. A machine's current rate is the minimum of its maximum rate, the production rate supported by input buffer 1, the rate supported by input buffer 2, and so on. Once the machine rate is known, its input-buffer consumption and downstream output follow.

P(t)=min(U,min(C1+K1Udt,s1(t)+v1(t)dt)K1dt,min(C2+K2Udt,s2(t)+v2(t)dt)K2dt,…)

These three equations, respectively from material conservation, blocking behavior and machine production, underpin the system properties of production controlled by blocking.

There are also splitter equations (see the paper).

Machine Dynamical-System Model ​

The continuous-flow model has many variables. To obtain a simple system for studying stability, impose certain conditions and restrict to a flow region, simplify the min/max expressions and eliminate some variables. This yields equations for machine production rates P.

See the paper for details.
