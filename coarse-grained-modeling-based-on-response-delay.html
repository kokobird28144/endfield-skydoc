5.3 Coarse-Grained Modeling Based on Response Delay (AI Content) ​

Source page ID: fG49ehIJlGAlBSw59KPVZZ | Open in Tencent Docs

Ko鸟's note: For systems that alternate between running and stopping (think of oscillating power generation), perhaps we can abstract a general simplified model. The main question is how to determine the total cycle length; the other quantities follow from it. (Starting from operating time or downtime works just as well.) For example:

  • Operating time = total cycle length * material supply rate / material consumption rate while running — material conservation.

  • Maximum buffer depletion = operating time * (material consumption rate while running - material supply rate).

  • Average output rate = operating time * output rate while running / total cycle length.

From this perspective, perhaps we can bypass a lengthy stage-by-stage analysis and reach a broadly reasonable conclusion. The following was written by the great Astra after I explained this idea.

Earlier, we calculated changes in the buffers of the conduit, machine and overflow branch separately to obtain the duration of each stage. Using the same setup and continuous-flow approximation, we now adopt a coarser description: treat the setup as a production system with constant input and delayed start/stop responses; first consider the balance over a complete cycle, then use the buffer conditions to determine its length.

We still assume that the actual Liquid Xiranite input rate is constant, the running machine has enough input material, no activation fluid is wasted, and insufficient conduit capacity never blocks input. All times below are in minutes, and flow rates are in units of fluid per minute. Brief starts and stops caused by individual fluid arrivals are excluded from this continuous-operation model for now.

5.3.1 How Much Accumulates During the Response Delay? ​

This setup uses overflow to trigger production. After the machine buffer fills and fluid begins to overflow, the machine still has to wait for the first unit of fluid to reach the activation port before starting. Under the earlier transport approximation, this response time is

τ=L120.

Input continues entering the setup during this wait, accumulating an amount

ΔSτ=v0τ.

Once running, the machine consumes 30 units of Liquid Xiranite per minute for production and requires another 6 units for each minute of activation. We therefore denote the total consumption per unit of operating time by

R=30+6=36.

This total consumption is expressed per unit of operating time. Activation fluid may enter the activation side in advance, so the setup need not consume fluid at exactly this rate at every instant. This equivalent rate can be used for the cycle balance provided that, at the end of a complete cycle, both fluid inventory and unused activation credit return to their initial states.

If the machine runs continuously after starting and only has to clear the fluid accumulated during the wait, its net processing rate is the total processing rate minus the continuing input. The required operating time is

W=v0τR−v0.

Thus, the same response delay produces a longer operating stage as input approaches the maximum processing rate: the machine must receive new input while clearing the accumulated inventory.

5.3.2 Closing the Cycle with Total Downtime ​

In the cases discussed earlier where input is below the production fluid-consumption rate, the machine buffer must refill after shutdown before overflow resumes. Downtime in a cycle therefore has two parts: the recovery time to refill the buffer, and the response time after overflow begins.

Denote recovery time, total downtime, operating time and cycle length respectively by

F,D,W,T.

They satisfy

D=F+τ,T=D+W.

Now consider material conservation for the whole setup. Liquid Xiranite entering during one cycle is ultimately used for production and activation. Inventory is the same at the beginning and end of the cycle, so

v0T=RW.

Substituting the time decomposition of the cycle gives

v0(D+W)=RW,

or

W=v0DR−v0,T=RDR−v0.

For the present setup, this becomes

W=v0(F+τ)36−v0,T=36(F+τ)36−v0.

Calculating the cycle now requires only the total downtime. The transport length determines response time, while recovery time summarizes the effects of buffer allocation and fluid-supply priority.

However, conservation alone does not determine recovery time. Even with the same input, maximum processing rate and response time, different buffer structures may produce different cycles. We still need a recovery-time relation based on the setup's mechanism.

5.3.3 Determining Recovery Time from the Two Earlier Branches ​

First consider input below 30, with the machine running continuously throughout the operating stage without input starvation.

When the overflow branch is not full and the conduit has no backlog, we previously obtained the decrease in the machine buffer:

C1−Slow=(30−v0)v0τ6.

After shutdown, external input replenishes this deficit, so

F=C1−Slowv0=30−v06τ.

Substituting into the coarse model gives

T=3636−v0(30−v06τ+τ)=6τ=L20.

When the overflow branch fills and the conduit develops a backlog, the conduit first keeps the machine buffer full. The buffer starts falling only after that backlog clears. From the corrected stage calculation, the duration of this decline is

B=τ+C26.

The recovery time is therefore

F=30−v0v0(τ+C26).

Substituting into the same cycle formula gives

T=3636−v0[τ+30−v0v0(τ+C26)]=1080τ+6(30−v0)C2v0(36−v0)=9L+6(30−v0)C2v0(36−v0).

This agrees with the earlier result obtained by splitting the cycle into stages. Here, we do not need to calculate the conduit-clearing time separately; its effect on operating time is already included in conservation over the complete cycle.

The two branches can also be combined. Using the earlier criterion for the branch filling, the buffer-depletion time is

B=min(v0τ6, τ+C26).

Recovery time and cycle length can then be written together as

F=30−v0v0B,T=3636−v0(τ+30−v0v0B).

The assumption of no input starvation is checked through the minimum buffer inventory:

Slow=C1−(30−v0)B>0.

Equivalently, this is the unified criterion obtained earlier:

(30−v0)min(20C2+L,v0L6)<120C1.

5.3.4 Simplification at Higher Input Rates ​

For input between 30 and 36, retain the approximation that the machine buffer stays full and the machine restarts only after a complete response time following each shutdown. There is then no recovery stage to refill the buffer:

F=0.

The cycle simplifies to

T=36τ36−v0=3L10(36−v0).

This result requires downtime in every cycle to equal the assumed response time. If activation fluid is still in transit at shutdown and causes an earlier restart, use the actual total downtime instead:

T=36D36−v0.

The coarse model can therefore also be used with observations. Even if the separate buffers cannot yet be calculated, confirming a stable cycle with no activation waste and measuring total downtime allows operating time and cycle length to be inferred from conservation.

5.3.5 How Does Response Time Affect Production Matching? ​

To compare different machines, define the input load fraction and the ratio of recovery time to response time:

ρ=v0R,α=Fτ.

The ratio of cycle length to response time is then

Tτ=1+α1−ρ.

The load fraction describes the remaining margin below maximum processing capacity, while the recovery-time ratio describes the extra waiting imposed by the buffer mechanism. At equal response time, a higher load fraction requires a longer operating period to clear inventory accumulated during downtime; a longer recovery stage also lengthens the cycle. When comparing layouts, remember that the recovery-time ratio may vary with pipe length and buffer capacity.

Response delay creates a mismatch within each cycle: input accumulates while the machine is stopped and is processed in a burst while it runs. Yet average inputs and consumption still match in this periodic model with no waste, input back-blocking or input starvation. The operating duty cycle is

WT=v036,

and the average gas-production rate is

v―gas=30WT=56v0.

Analysis of response time should therefore distinguish average output from production fluctuations. In the present model, response delay mainly affects cycle length, running and stopped durations, and inventory requirements. Actual average output must be recalculated only when the fluctuations additionally cause input starvation, input back-blocking or activation waste.

This coarse model retains four quantities: input, total processing capacity, response time and recovery time. Use conservation over a complete cycle to determine the ratio of operating time to downtime, then use the buffer mechanism to determine recovery time. This reproduces the earlier cycle results and also helps analyze other machines with similar start/stop mechanisms.
